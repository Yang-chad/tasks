🧮 自动计算算法（前端 ReviewRequirementView 源码还原）

// 1. 按类型累加工时
总工时 total = Σ(全部类型工时)
开发工时 dev = 前端 + 后端 + 移动端 工时之和
产品工时 prod = 产品类型工时
测试工时 test = 测试类型工时

// 2. 归一化（基准 7.25 人·天，除以各档天数）
d_total = total / 7.25 / 14
d_dev = dev / 7.25 / 6
d_prod = prod / 7.25 / 2
d_test = test / 7.25 / 3

// 3. 自动计算分数
auto = 上述 4 项中 有效值(>0)的平均值；若有效值 < 3 个，则 退化为 d_total
💡 解读：系统把一个需求的工时按「总量 / 开发 / 产品 / 测试」拆成 4 个维度，各自按不同"标准天数"（14/6/2/3 天）折算成无量纲分值，再取平均，得到需求综合规模分（用于量化评审参考）。 当前页面中「自动计算」列即该值，分数范围受工时规模影响，无硬性 1-5 上限（前端输入框 autoMin/autoMax=1/5 仅用于筛选，非算法钳制）。
